# Kit 03 — Minors & guardian consent checklist (v0.1.0)

**For programs hosting observers under 18.** This is a checklist template, not legal advice. Use your school/hospital counsel-approved forms.

## Before first visit

- [ ] Written guardian consent on file
- [ ] Emergency contact recorded
- [ ] School affiliation letter / HOSA chapter approval (if applicable)
- [ ] Site orientation completed (privacy, safety, dress code)
- [ ] Immunization / TB / flu requirements documented per site policy
- [ ] Background check / badge process status noted
- [ ] Restrictions documented (no OR, no psych, hours limits, escort required)

## Day of

- [ ] Guardian knows location and end time
- [ ] Site coordinator confirms escort / mentor assignment
- [ ] Observer understands they may be asked to leave sensitive encounters

## Data / discovery

- [ ] Minor observers excluded from public discovery directories if using ProMedNet or similar tools
- [ ] No posting of site experiences that identify patients or staff without authorization
